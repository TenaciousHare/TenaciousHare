# Hi, I'm Paweł 👋 ✈️

**Junior Front-End Developer** from Tarnowskie Góry, Poland — building web apps that solve real problems in the **aviation industry**, where I know the workflows from the inside.

I focus on React and TypeScript, and I care about shipping: every project below is deployed and running.

---

### 🚀 Featured projects

**[✈️ Aviation Destinations](https://github.com/TenaciousHare/Destinations)** — [live demo](https://destinations-test.netlify.app/)
Generator of printable route-knowledge tests for airport staff, with a secured trainer panel.
`React` · `Vite` · `Firebase (Auth + Firestore)` · `React Router (Protected Routes)`

**[🛫 Manual Boarding](https://github.com/TenaciousHare/ManualBoarding)** — [live demo](https://manual-boarding.netlify.app/)
Seat-map generator for practicing manual check-in and aircraft section counting under time pressure.
`TypeScript` · `Vite` · `Playwright (e2e tests)` · bilingual docs (PL/EN)

**[✈️ Avia Weather — METAR & TAF](https://github.com/TenaciousHare/avia-weather)** — [live demo](https://avia-weather.netlify.app/)
Aviation weather viewer for any airport by **ICAO or IATA** code. Shows the raw METAR and TAF alongside plain-language decoding of cloud cover, flight rules and TAF change types, with flight category, ISA deviation, a freshness indicator and a dark mode.
`React` · `TypeScript` · `Vite` · `TanStack Query` · `Netlify Functions` · `Vitest` · `GitHub Actions CI`

**[🐰 Zając na Froncie (blog)](https://github.com/TenaciousHare/zajac-na-froncie)** — [live site](https://zajac-na-froncie.netlify.app/)
A Polish blog where I document how I build these projects, step by step — honest, mistakes included. Scheduled posts, dark mode, RSS and comments.
`Astro` · `MDX` · `Tailwind CSS` · `Netlify`
